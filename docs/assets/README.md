# Website assets

`docs/assets/` contains files that are published with the GitHub Pages site.

- `icons/wheel-mcp.png`: the current Wheel-mcp brand mark copied from the supplied `Crop.png`.
- `icons/favicon.png`: browser favicon using the same brand mark.
- `icons/claudecode.webp`: Claude Code.
- `icons/githubcopilot.webp`: GitHub Copilot / VS Code.
- `icons/openai.webp`: OpenAI / Codex.
- `icons/windsurf.webp`: Windsurf.
- `icons/cursor.webp`: Cursor.
- `icons/godot-logo.svg`: Godot runtime target.
- `icons/trae.webp`: Trae icon sourced from the LobeHub static icon package for the manual MCP profile card.

Keep website images and icons here rather than mixing them with JavaScript and CSS.
Do not add secrets, local absolute paths, or private project exports to this directory.
