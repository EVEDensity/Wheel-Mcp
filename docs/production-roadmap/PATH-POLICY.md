# T09 项目文件与资源路径策略

`src/project/paths.ts` 是通用项目文件入口。MCP 授权层与实际的场景、脚本、静态场景树、文本文件、搜索和修复/精确编辑入口共用同一语法与文件解析。`res://` 去掉协议前缀后按项目相对路径验证；经批准的绝对路径必须落在项目根内；`uid://` 只在读取时扫描真实 Godot `.gd.uid` 或 `.tscn/.tres` 资源头，唯一匹配才解析，不作字符串拼接。UID 扫描跳过隐藏目录与链接，有 10000 项预算。

路径分量禁止空值、`.`、`..`、反斜杠、控制字符、冒号（含 Windows ADS）、末尾点与空格。读取要求目标为现存普通文件；写入允许现存普通文件或现存父目录下的新文件，不自动创建父目录。每一级检查盘上实际名称、真实路径和 `lstat`，拒绝符号链接、Windows junction、目录穿越及写入多硬链接文件。Windows 路径大小写必须与磁盘一致。UNC 根/UNC 输入和盘符相对路径不受支持。`.git`、`.godot`、`.harness` 为内部受保护区，通用读写均拒绝；内部证据/引擎功能须走其专用策略，不能借通用文件工具访问。

证据输出不按项目路径解析：由独立 `evidenceRoots`、桥接 session 证据目录和对象归属授权。以上检查可阻止静态路径穿越、链接与 junction，但不是 OS 沙箱。路径检查完成后到 `readFile`/`writeFile` 之间，拥有本机文件系统写权限的恶意并发进程仍可能调换父目录；Windows 当前实现没有可证明的目录句柄级无竞态打开。项目文件操作只在受信本地主机/项目下提供；非 loopback HTTP 绑定即使设置 `MCP_HTTP_ALLOW_REMOTE=true` 也拒绝。不得经公网反代绕过这个限制。T10 的事务/锁和后续安全验收须重新评估远程资格，不能把此处的字符串与真实路径检查称为沙箱。
