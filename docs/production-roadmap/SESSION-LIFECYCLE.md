# Runtime session and write-operation contract (T07, Windows-scoped)

The persistent runtime path uses `open_runtime_bridge` to obtain a `sessionId`. Every stateful bridge call supplies that ID. The legacy `get_runtime_property`, `set_runtime_property`, `inject_runtime_input`, and `capture_runtime_screenshot` tools each launch a separate Godot process; they do **not** share state. Use `call_runtime_bridge` for `set_property`, `inject_input`, `get_property`/`get_game_state`, and `capture_screenshot` in one explicit session. A real Godot regression verifies shared state, PNG capture, and isolation from a second session.

An explicitly requested `sessionId` is reserved before Godot starts. A duplicate active, opening, or recently stopped ID fails `CONFLICT` and cannot replace another bridge. `stop_runtime_bridge` is idempotent for a previously stopped ID; a never-created ID returns `NOT_FOUND`. The stopped-ID tombstone cache is bounded to 1,024 entries and is process-local.

`call_runtime_bridge` accepts an optional `operationId` on mutating methods (`set_property`, `create_node`, `delete_node`, `call_method`, `reload_scene`, `inject_input`, and `capture_screenshot`). When omitted, the server generates one and returns `operation_id` on success. The same ID with the same method and arguments in a live session returns the first result without redispatching. Reuse with different arguments fails `CONFLICT`. An aborted or timed-out write returns code `UNKNOWN` with `sessionId` and `operationId`, not a claim that the write failed. Query `get_runtime_operation_status` before deciding what to do; it reports `PENDING`, `UNKNOWN`, `COMPLETED` with the Godot result, or `FAILED` with the error. A late response updates the status and is recorded in `responses.jsonl`. The ledger holds at most 4,096 operation IDs per session. Never blindly replay an `UNKNOWN` write under a new ID.

Launches and persistent bridges now share one durable run registry, quota, owner PID, exit record, and unique run/session ID namespace. The default quota is 32 live processes and can be lowered with `GODOT_HARNESS_MAX_CONCURRENT_RUNS`. `GODOT_HARNESS_RUN_REGISTRY_PATH` selects a shared registry file; writers take a cross-process lock and re-read before changing it. A lock left by a dead owner is recovered. An active duplicate session ID cannot replace an earlier process record. Terminal records retain their IDs rather than silently overwriting evidence.

On Windows, launch and bridge processes record OS creation time and executable path. Stop, cancel, and orphan reclaim verify both immediately before terminating the captured process; a missing or changed identity fails closed. A new owner can reclaim a live Godot process after the prior owner crashes, as verified with a real detached Godot process. On Linux, identity can be read but verified signalling is not yet implemented, so live-PID termination remains `UNSUPPORTED` rather than risking PID reuse. Windows is the first verified production scope; Linux is not.

An explicit HTTP MCP session DELETE closes its owned run and bridge. If the HTTP client disappears without DELETE, an idle lease closes the session and resources after 5 minutes by default (`MCP_HTTP_SESSION_IDLE_TIMEOUT_MS`); active requests and SSE streams keep the lease alive. Stdio EOF, transport close, SIGINT and SIGTERM start separate-budget cleanup. A hard-killed owner cannot run shutdown hooks; the next service/registry owner scans ORPHANED records and verifies identity before reclaiming. Scenario cleanup also has its own stop budget and uses the verified registry rather than a raw PID.

Limits: write-operation status is process-local, so after a server crash an in-flight write remains epistemically `UNKNOWN`; never replay it under a new ID without re-reading game state. HTTP idle cleanup is bounded, not instantaneous. Registry lock recovery is fail-closed if a lock's PID has been reused or a separate recovery guard is abandoned. Platform, ownership and long-run soak gates remain subject to later roadmap tasks; this document does not by itself grant production qualification.
