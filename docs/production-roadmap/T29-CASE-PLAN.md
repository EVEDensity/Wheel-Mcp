## 执行边界

固定 30 例，五类各六例。runner 仅使用官方 MCP SDK 发送固定请求；不调用模型、自动生成方案或放宽 oracle。运行前冻结请求、许可范围、场景/资源 SHA、容差、版本、传输、超时、预算及批准行为；批准 fixture 明确为 MOCK。

每例独立项目/客户端会话，记录 initialize/discovery/call 协议结果、编辑器/运行时结果、保存重开读回、失败对照、原始文件哈希和恢复/进程清理。资源句柄、事务 ID 和会话 ID 只能由前一步结果绑定，不能填造。未知写入先查询状态，不自动重提。

## 案例分组

每个案例必须附精确 JSON 请求、独立断言和非法输入对照后才能冻结为可执行案例。当前节点组的固定请求与 oracle 位于 tests/helpers/production-cases.ts，runner 为 tests/production-case-e2e.test.ts；其余分组仍是范围清单，不是通过报告。逐例证据、输入摘要和双轮固定 oracle SHA 纳入正式验收 manifest。

### N01–N06 节点/场景

- N01：create → set → save/reopen → tree/property 读回；对照非法父路径；失败无部分写入。
- N02：rename → save/reopen → 新旧路径断言；对照名称冲突；恢复原节点名。
- N03：move/reparent → save/reopen → 层级/所有权读回；对照环形层级；恢复原父节点。
- N04：instantiate 固定源 SHA → 保存重开 → 实例来源读回；对照源 SHA 冲突；源场景不变。
- N05：connect → 保存重开 → 信号连接读回；对照非法方法/越权调用；无非法连接残留。
- N06：原子批次 → Undo/Redo → 保存重开；对照中途非法操作；逐文件/层级恢复。

### U01–U06 UI

- U01：Control 锚点/边距 → 保存重开读回；对照无效数值；布局恢复。
- U02：Label/Button 文本与状态 → 保存重开；对照不允许的属性；无额外属性写入。
- U03：VBox/HBox 子级布局 → 原生运行读回；对照非法子级路径；恢复顺序。
- U04：Theme 字体/颜色/常量 → 持久化引用读回；对照超范围值；资源与节点均恢复。
- U05：StyleBoxFlat 创建/唯一分配 → 保存重开；对照跨会话句柄；共享资源不被隐式修改。
- U06：UI 固定输入 → 状态/事件 → 截图；对照只读客户端写入；输入释放与独立基准保留。

### P01–P06 3D/碰撞

- P01：Node3D 变换 → 保存重开/运行读回；对照非法 Variant；变换恢复。
- P02：BoxMesh 创建/分配 → 保存重开；对照错误句柄类型；无错配残留。
- P03：静态碰撞体/Shape → 原生碰撞查询；对照负 mask；场景/资源恢复。
- P04：RayCast3D 固定刷新 → 命中/只读重查；对照缓存过期；不伪造新采样。
- P05：ShapeCast3D 有界 overlaps → 唯一对象断言；对照历史预算超限；不污染缓存。
- P06：物理帧屏障 → 固定输入 → 状态断言；对照旧事件游标；取消后释放输入并停止进程。

### A01–A06 动画/材质

- A01：动画轨道/关键帧 → 保存重开读回；对照无效轨道路径；动画恢复。
- A02：固定播放/seek → 原生状态读回；对照不支持的方法；不绕过方法授权。
- A03：动画复制/唯一化 → 两实例读回；对照共享策略冲突；源资源不变。
- A04：StandardMaterial3D 创建/唯一分配 → 保存重开；对照非法 roughness；资源恢复。
- A05：受限文本 shader → 原生验证/渲染；对照非法源码；不得忽略 shader 诊断。
- A06：受限 visual shader 图 → 保存重开/渲染；对照非法边/端口；图与资源恢复。

### S01–S06 脚本补丁/诊断

- S01：固定正确两文件候选 → 精确批准 → 原生验证/读回；对照错误基线 SHA；无并发覆盖。
- S02：错误候选 → 固定断言失败 → 原文件逐字读回；正确不同候选成功；不放宽阈值。
- S03：拒绝批准 → 无写入；对照 approved=true 无有效 host receipt；不能当作批准。
- S04：重复 ID/相同内容换 ID → 明确拒绝/预算不变；状态查询关联原候选；不重放。
- S05：语义符号/引用 → rename preview → 精确批准/原生验证；对照外部范围或监听身份不符；安全拒绝。
- S06：固定语法/运行/关闭期诊断 → 有界证据；对照取消/交付失败；未知状态查询及恢复读回。
