## 入口与判定

先 npm.cmd run build；node scripts/soak-production.mjs --plan 显示冻结计划。

--smoke 为 4 循环；--smoke-paced 为 90 秒遥测预检；--smoke-stress 为 40 循环留存压力预检，都不能替代 1,000 次实测。

--workload 不按时间空等，执行固定 1,000 次后评估。独立启动使用隐藏窗口和私有 stdout/stderr，核对 OS 出生身份及实际进度；不依赖临时终端存活，不承诺跨休眠/重启续跑。
