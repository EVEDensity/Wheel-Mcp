# 功能现状与后续优先级

核对日期：2026-10-18；源码版本字段：0.2.8。本清单记录实现，不把“存在接口”当成全场景验收通过，也不授予新的稳定版资格。

当前完整发现面为 **71 个 MCP 工具**：项目 23、运行时 33、诊断 4、场景验证 8、证据 3。只读配置会缩小工具列表。逐个工具名见[工具目录](TOOL-CATALOG.md)，实际参数以运行中服务的 `tools/list` 为准。

## 已实现的功能（逐项）

1. **安装与接入。** 提供 CLI、stdio MCP 服务、项目级/全局安装与配置助手；更新时保留客户端自有配置并备份变更。Codex/Cursor 等配置适配不等于所有客户端真实审批链已认证。
2. **环境检查。** 检查 Godot 版本、路径和项目接入问题。当前稳定范围是可信本地项目、Windows、Godot 4.7.2、stdio；引擎需要单独安装。
3. **项目读取与搜索。** 查找项目、读取项目元数据、文本和静态场景树，搜索代码、分析节点语义和静态碰撞配置。
4. **上下文与索引。** 提供词法级符号、节点、依赖和诊断视图以及 context pack；刷新读取并返回源哈希与截断信息。词法关系不是引擎语义或安全重构证明。
5. **标准 MCP Resources / Prompts。** 已有五种项目资源视图、会话所有的续页资源，以及 implement_feature、troubleshoot_error、build_ui、verify_candidate 四类提示。内容有权限、字节和会话边界；不是自主规划或自动执行。
6. **后台启动与进程管理。** 默认 headless 启动，查询、取消、停止所属运行，识别并回收登记的孤儿进程。只清理有所有权证据的进程，不随意关闭用户的 Godot。
7. **持久运行时会话。** 同一个 sessionId 内复用游戏实例，查询运行场景树、属性和专用状态，注入输入、调用受控方法、增删运行节点与重载场景。运行时变更不等于场景已保存。
8. **事件订阅。** 按游标读取事件，支持订阅、暂停、轮询、确认、取消、关闭和恢复读取；不意味着存在完整物理接触事件历史。
9. **运行验证。** dev_loop、Scenario、测试场景、等待事件、属性断言及失败诊断组成有界验证链。服务不内置模型来任意生成代码或循环直到通过。
10. **截图与视觉证据。** 真实渲染器输出 PNG，支持 RGBA 像素差异、近期证据与分页读取。截图默认屏外启动，运行桥确认最小化和 unfocusable 标志；这不能代替操作系统焦点观察。已有 headless 会话没有可截图帧缓冲。原生首窗、系统/驱动弹窗及任务栏入口仍可能出现，不能保证所有环境绝对不抢焦点或无窗口。
11. **实时输出与诊断。** 读取 stdout/stderr 的有界分段与游标，关联运行和失败证据。脚本结构分析只是启发式；实际语法查询需已授权编辑器的 Godot LSP。
12. **脚本语义和重命名预览。** 支持 LSP 符号、引用、定义、诊断及带定义一致性检查的重命名候选预览。预览只读，不直接重命名；原始引用可能包含字符串和注释，仍需影响审查。
13. **安全文件写入。** 精确计划、宿主审批、项目根目录与哈希检查、事务日志、失败回滚和恢复。引擎文件默认先隔离验证；raw 模式须单独风险批准且标记 NOT_RUN。approved:true 不是授权；本地预授权也不是全权限放行。
14. **客户端修复协作。** begin/submit/status 协议固定原始条件，接受客户端候选、精确批准后验证，失败回滚；不确定响应先查状态，不盲目重提。不是自动修复模型。
15. **Git 恢复证据。** 支持检查点与显式 UTF-8 文本补丁的受控反向恢复；不是任意 git reset/checkout 或二进制恢复。
16. **原生编辑器场景操作。** 支持声明节点的创建、删除、重命名、重设父节点、受控实例化、继承覆盖、属性和信号操作；每批最多 32 操作、场景最多 100 节点，一批对应一次原生 Undo/Redo。含脚本、未声明类型或唯一名称节点的文档不支持这类批量编辑。
17. **原生资源管理与保存。** 公开 v0.2.8 为 14 类资源，main 新增第 15 类有界 GradientTexture2D；提供有归属的句柄、读取、复制、引用、受控赋值和原生导出。场景/资源保存另行批准，检查序列化读回、UID、依赖和磁盘冲突；产品不会强行重载正在编辑的文档。新纹理只读，不允许原地 resource_set；从外部导出引用时必须显式独占复制后内嵌。
18. **UI 子集。** 基础控件、容器布局、Theme、StyleBoxFlat、焦点/鼠标等声明字段与有限 pressed→hide/show 信号。main 新增 LineEdit、ScrollContainer、纯文本 RichTextLabel，以及 TextureRect 的扩展模式 0..1、拉伸 0..6、翻转和最多 32×32 的内嵌双色原生渐变；保留原生 Undo/Redo 和实际保存重开。滚动位置不是 authored 字段，内部控件不可通过场景路径编辑。任意 PNG/SVG 纹理引用、RichTextLabel BBCode/图片/链接/特效/非持久格式栈、IME、鼠标滚轮/触摸、文本信号、任意脚本回调和字体资源图仍不在此子集内。
19. **3D 与物理子集。** 基础变换、网格、静态碰撞、Area3D、RayCast3D，以及物理帧调度的 overlap/ray/intersect_shape 查询。专用状态可读取 Camera3D / NavigationAgent3D；不包含完整角色/刚体原生创作、骨骼、导航烘焙或完整接触事件流。
20. **动画子集。** 本地位置关键帧、有限状态机、双源 Blend2 和播放状态读回。尚不支持旋转/缩放、骨骼、音频、方法轨道、任意嵌套图或导入动画原位修改。
21. **材质与 Shader 子集。** 基础材质颜色/粗糙度/金属度，两个固定 spatial/unshaded 模板及有界 Color/Mix 图。不是任意 Shader、完整 PBR、纹理资源图或完整 VisualShader 编辑器。
22. **内容导入与场景迁移。** 项目内 PNG 有严格字节、尺寸、校验和隔离导入限制；场景移动具引用影响检查、UID 保留和引擎验证。部分演示通过批准后的 .tscn 文本事务接入脚本/其他节点，不属于原生 Undo 创作；没有任意资源导入器和通用资源重命名。
23. **权限与传输。** stdio 是当前稳定入口；HTTP 具有认证、根目录、scope 和会话隔离等控制，但不具备公网部署资格。编辑器插件须主动授权；项目脚本仍以本机权限运行，headless 不是沙箱。
24. **分发、站点与证据。** GitHub 包、SBOM、验收回执、校验和、短 CI 与按标签触发的发布门禁；双语介绍站与浏览器演示独立于真实 MCP。受控效率实验不是实际账单、速度或所有项目的收益保证。

高级 UI、3D、动画、材质、Shader 等属于有界、实验性创作能力。详见 [UI](production-roadmap/UI-AUTHORING-CONTRACT.md)、[物理](production-roadmap/PHYSICS-3D-CONTRACT.md)、[动画](production-roadmap/ANIMATION-AUTHORING-CONTRACT.md)、[Shader](production-roadmap/SHADER-AUTHORING-CONTRACT.md)、[内容工作流](production-roadmap/CONTENT-WORKFLOWS-CONTRACT.md)契约。

## 建议后续新增或扩展（尚未完成，不是交付承诺）

1. **已完成 P0：自动发布闭环（v0.2.8）。** 只验收和正式标签两轮完整门禁均通过，自动上传、公开发布和下载复验通过，同一源码与运行包哈希一致。后续维护继续保留准确 ID、失败闭锁、独立校验和不可变标签，不把一次通过当成永远不会出现外部服务或 runner 故障的保证。
2. **P0：真实项目可用性（进行中）。** main 开发源码已补超时后的防误重试提示、并发隔离及迟到批准回归。本轮进一步让配置中的启动入口直接运行在客户端所属 PID，缺包/入口不兼容时仅 stderr 提示，不隐式构建；新增入口 EOF、异常退出、替换后重启、SDK 重连及真实 Godot 孤儿回收检查。安装包和 Codex 原生接口探针改走该入口。继续回查人工审批、实际更新交互和截图焦点；探针批准仍为 MOCK，不能冒充人工 UX 通过。v0.2.8 发布包不包含这些 main 开发改动；Cursor 待具备条件再验收。
3. **P1：常用 UI 与交互（逐控件推进）。** LineEdit、ScrollContainer、RichTextLabel 纯文本子集已通过自动限域验收；main 继续增加 TextureRect 与有界原生渐变引用，不声称已完成任意图片支持。宿主/插件配套升级要求见 [UI 契约](production-roadmap/UI-AUTHORING-CONTRACT.md)。后续继续带文件哈希、导入来源及依赖 CAS 的受控 PNG 纹理引用；字符输入与 IME、鼠标滚轮/触摸及信号白名单仍需分步实现及实际验收，不因个别控件通过而声称 UI 全覆盖。
4. **P1：可用的 2D/3D 创作链。** 优先 Sprite2D、CharacterBody2D/3D、RigidBody3D 的声明子集，以及脚本挂载的明确安全契约。先完整跑通一个角色控制/交互最小闭环，再扩骨骼、导航和复杂物理；不一次性声称完整 Godot 支持。
5. **P1：动画扩展。** 在位置轨道之外增加旋转、缩放和更多受控混合节点；导入动画用非破坏性副本策略。每步都验证资源归属、运行读回和保存重开。
6. **P1：材质、纹理与 Shader。** 补受控纹理引用和常用 PBR 字段，再考虑参数化 Shader 或更多有类型的 VisualShader 节点；增加编译错误定位与真实像素验证，不直接开放任意代码写入绕过审批。
7. **P2：安全重构与上下文质量。** 在已有词法索引、Resources/Prompts、分页和只读重命名预览上加强失效提示、增量刷新和跨文件影响核对。直接应用语义重命名前需更强定义证明、独立批准与保存回读，不把现有预览描述成已完成自动重构。
8. **P2：安装、升级与维护。** 补独立机器、Linux/macOS 和其他客户端的实际验收；实现可解释的预检/更新回退体验。继续缩小无用日志，保留必要失败摘要、回执和不可替代证据，清理前保护正在运行的会话。

不恢复已明确排除的强制八小时验收，不增加每次提交都运行的长 CI。扩展项按用户真实需求、小范围实现和逐步验收推进；缺少的环境或未执行项必须保留 NOT_RUN，不能靠删除记录变成 PASS。
