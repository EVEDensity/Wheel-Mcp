BRING YOUR OWN GAME

让你的 Godot 游戏也能直接玩。

  1. 导出适合静态托管的版本

    使用 Godot Web 导出，选择 Compatibility 渲染器并关闭线程支持。不同 Godot 版本的具体选项请核对官方文档；C# 项目 Web 支持也需要单独核对。

  2. 保留完整的导出文件

    将 HTML、JS、WASM、PCK 等完整放到 docs/games/godot-lab/web/。不要只复制 HTML，也不要引用你电脑上的绝对路径。

  3. 接入这个预留页面

    在 docs/games/godot-lab/index.html 添加指向 ./web/index.html 的「开始游戏」链接，或使用带标题的 iframe 嵌入。先测试导出页本身，再把试玩厅卡片标记为可玩。

  4. 在仓库子路径下验证

    运行 npm run site:serve，访问终端中的 /Wheel-mcp/ 地址。检查资源加载、音频、键盘、触控与刷新后的深层页面。本站预览服务只用于本地开发，不是游戏后端。

!

多线程导出依赖安全上下文及跨源隔离；本站不会用 Service Worker 偷偷改变宿主行为。若游戏必须使用多线程，请改用可配置所需响应头的托管服务。大体积游戏还需检查 GitHub 文件和 Pages 站点限制。

PUBLISH / GITHUB PAGES

一个文件夹，就是一个网站。

将文件提交到 main 后，打开仓库 Settings → Pages。Source 选择 Deploy from a branch，Branch 选择 main，Folder 选择 /docs，然后保存。等待 GitHub 完成部署。

本地预览不等于已发布；本次实现不会自动提交、推送或修改你的仓库设置。
